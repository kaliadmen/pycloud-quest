# Boss Fights

One per phase. Rules:
1. Build it from scratch in a new folder here (`boss-fights/bfN-name/`). No notes, no lesson code open, no AI.
2. Python docs (docs.python.org) are allowed. Real engineers use docs.
3. Time-box it to one weekend session. Unfinished is fine; it shows what to review.
4. Push it and ask Claude to review. Results go in `PROGRESS.md`, weak spots go in the review queue.

| # | After phase | Task |
|---|---|---|
| 1 | Phase 1 | File-integrity snapshot tool: hash every file in a folder, save a JSON baseline, report added/removed/changed files on the next run. Structured logs. Tests. |
| 2 | Phase 2 | TCP chat server: many clients, usernames, broadcast, graceful disconnects, a max message size. |
| 3 | Phase 3 | Policy evaluator for a new rule set Claude gives you on the day. |
| 4 | Phase 4 | Presigned-URL service: HMAC-signed links that expire and can't be tampered with. |
| 5 | Phase 5 | A detection rule plus sample logs for an attack Claude describes, with tests proving it fires and doesn't false-positive. |
