# app/: Drop

Drop is a secure file-sharing web app that runs **on Nimbus** (Phase 6). Accounts, uploads stored in Nimbus
object storage, expiring share links, secrets from the Nimbus secrets manager, and every action logged.

It is built in Phase 6. In Phase 7, a planted-vulnerability branch of it becomes the OWASP lab.
Stretch goal: a cloud-save and leaderboard endpoint for the JRPG from the C/C++ course.
